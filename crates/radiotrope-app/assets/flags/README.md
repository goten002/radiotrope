# Country flags

40×30 PNGs rendered from the 4x3 SVGs of
[flag-icons](https://github.com/lipis/flag-icons) 7.5.0 (MIT, see `LICENSE`),
one per ISO 3166-1 alpha-2 code. The [country name table](../../../radiotrope-library/assets/country-names.tsv)
comes from the same package's `country.json`.

The app build script embeds the PNGs at compile time.
