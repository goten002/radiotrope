# Country flags

40×30 PNGs rendered from the 4x3 SVGs of
[flag-icons](https://github.com/lipis/flag-icons) 7.5.0 (MIT, see `LICENSE`),
one per ISO 3166-1 alpha-2 code. `names.tsv` maps country names to codes and
comes from the same package's `country.json`.

They are compiled into the app by `build.rs`; nothing is fetched at runtime.
